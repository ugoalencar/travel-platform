# Documentation Skill

## Descrição
Skill para criar e manter documentação do projeto.

## Quando usar
- Documentar nova feature
- Documentar arquitetura
- Escrever guias de setup
- Documentar APIs
- Atualizar README
- Criar guides

## Estrutura de Docs

Consultar `docs/`:
- `00-product/` - Product overview
- `01-architecture/` - Arquitetura técnica
- `02-domain/` - Domain model
- `03-security/` - Segurança
- `04-database/` - Schema e queries
- `05-api/` - API documentation
- `06-frontend/` - Frontend patterns
- `07-testing/` - Test strategy
- `08-devops/` - Deployment e infra
- `adr/` - Architecture Decision Records

## Tipos de Documentação

### README
- Overview do projeto
- Quick start
- Contribuindo
- Troubleshooting

### Architecture Decision Records (ADR)
- Quando: Alteração arquitetural significativa
- Formato: Status, Context, Decision, Consequences
- Arquivo: `docs/adr/NNNN-decision-title.md`

### API Documentation
- Endpoints
- Parâmetros
- Responses
- Exemplos
- Autenticação

### Guides
- Setup local
- Deployment
- Running tests
- Common tasks

## Padrões
- Markdown files
- Keep it updated
- Exemplos práticos
- Links para código relevante
- Versionado com código

## Verificações
- [ ] Documentação clara e completa
- [ ] Exemplos funcionam
- [ ] Links corretos
- [ ] ADR criado se necessário
- [ ] README atualizado
