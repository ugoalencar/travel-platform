# Create Feature Skill

## Descrição
Skill especializada em criar novas features seguindo a arquitetura e padrões do projeto.

## Quando usar
- Implementar nova funcionalidade
- Adicionar feature completa (backend, frontend, testes)
- Seguir padrão de project structure

## Processo
1. Verificar regras obrigatórias em `AGENTS.md`
2. Consultar arquitetura em `docs/01-architecture/`
3. Verificar domain em `docs/02-domain/`
4. Implementar backend (se necessário)
5. Implementar frontend (se necessário)
6. Criar testes automatizados
7. Documentar em ADR se decisão arquitetural
8. Validar isolamento entre agências

## Verificações
- [ ] Regras obrigatórias seguidas
- [ ] Arquitetura mantida
- [ ] Testes implementados
- [ ] Documentação atualizada
- [ ] Isolamento de agência garantido
