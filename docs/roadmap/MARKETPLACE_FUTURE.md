# Roadmap futuro — META 02: Travel Marketplace / External Inventory

Este documento existe apenas para **registrar** a próxima meta como futura. **Nenhuma implementação foi feita** nesta rodada (META PÓS-PILOTO 01 — Platform Admin Comercial & Parcerias) nem está planejada para começar automaticamente depois dela.

## O que é a META 02

Travel Marketplace / External Inventory — uma camada de inventário de viagens vindo de fontes externas (GDS, consolidadoras, fornecedores terceiros), disponibilizada dentro da plataforma para as agências comercializarem.

## Explicitamente fora de escopo até uma decisão futura de produto

- Marketplace
- Amadeus
- GDS (qualquer integração)
- Emissão de passagem
- Inventário externo
- Booking externo
- Settlement de marketplace
- Billing recorrente completo
- Pagamento automático de comissão

## Por que este registro existe agora

A META PÓS-PILOTO 01 criou a camada comercial (Landing CMS, Banners, Parceiros, Indicações, Comissões, Créditos) que é a base de relacionamento comercial da Travel Plataforma com parceiros e agências. Um Marketplace real dependeria dessa camada existir primeiro (ex.: um parceiro de inventário seria um `platform_partners` com um tipo de relação diferente) — mas construir o Marketplace em si é uma decisão de produto separada, maior, e não solicitada nesta rodada.

Nenhum código, migração, rota ou tela desta meta futura foi criado.
