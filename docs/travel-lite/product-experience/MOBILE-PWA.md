# Travel Lite — Mobile e PWA

## Objetivo

Oferecer uso leve no celular para consulta e captação rápida fora do ambiente comum da agência. O foco inicial não é substituir o desktop, mas permitir ações de campo.

## Escopo mobile inicial

- Login.
- Dashboard resumido.
- Cadastro rápido de cliente.
- Consulta de clientes.
- Consulta de vendas próprias.
- Acesso à ajuda.

## Cadastro rápido de cliente

Campos mínimos:

- Nome.
- Telefone/WhatsApp.
- E-mail opcional.
- CPF opcional.
- Observação curta.

Regra: se o usuário for SELLER, o cliente deve ficar vinculado ao vendedor logado quando aplicável.

## Dashboard mobile

Mostrar apenas indicadores essenciais:

- vendas do mês;
- valor vendido;
- recebidos;
- pendências;
- ranking/resumo quando houver permissão.

## PWA

Requisitos:

- manifest com nome e ícones;
- tela responsiva;
- instalação pelo navegador quando suportado;
- funcionamento online-first.

## Fora do escopo imediato

- Offline completo.
- Push notification.
- Scanner/OCR.
- App nativo.

## Critérios de aceite

- App usável em largura mobile.
- Cadastro rápido funciona em poucos campos.
- SELLER não vê dados fora do próprio escopo.
