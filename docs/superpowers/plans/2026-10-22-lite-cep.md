# Travel Lite ViaCEP Implementation Plan

**Goal:** Consultar CEP no cadastro de clientes local sem bloquear cadastro manual.
**Architecture:** Fastify autentica e autoriza a consulta; um servico limitado
consulta somente ViaCEP, valida resposta e guarda cache temporario limitado.
React preenche somente campos vazios e nao alterados durante a consulta.
**Tech Stack:** TypeScript, Fastify, React, Vitest, fetch nativo.

## Constraints

- ViaCEP autorizado pelo usuario em 2026-10-22; nao usar API Correios.
- Sem dependencias novas, migracoes, commit, push ou deploy.
- Manter documentos dos outros agentes e dados de clientes intactos.
- Nao logar CEP/token/corpo remoto. Consulta envia somente CEP.
- Somente permissoes existentes de criar/editar clientes autorizam consulta.
- CEP invalido legado inalterado nao deve impedir editar outro campo.
- Limites por instancia nao representam protecao distribuida de producao.

## Tasks

1. Testar em RED normalizacao, provider, timeout, respostas invalidas, cache,
   limite, autorizacao e fluxo da UI com respostas atrasadas/edicao manual.
2. Implementar services/api-lite/src/cep.ts e routes/cep.ts; integrar app.ts.
   URL fixa, sem redirects, body limitado, timeout de 3s, cache 24h max 500
   CEPs, dez consultas/minuto por usuario/tenant e limite global de saida.
   Um servico por app compartilhado por ambas as variantes de rota.
3. Validar CEP novo/alterado em POST/PATCH com normalizador comum; preservar
   CEP legado quando nao alterado. Testes puros sem alterar banco.
4. Adicionar campo de CEP com preenchimento assistido e mensagens de estado,
   retry, debounce e cancelamento. Numero/complemento nao sao automaticos.
5. Rodar testes focados e regressao frontend, lint, typecheck, builds Lite.
6. Disponibilizar API atualizada somente local em porta livre; usar proxy
   Vite e validar health/autorizacao e fluxo demo no browser desktop/mobile.
   Nao encerrar processo existente sem necessidade.
7. Registrar resultado e limites na documentacao Lite. Folha/comissoes
   permanecem outra frente, nao serao declaradas implementadas neste lote.
