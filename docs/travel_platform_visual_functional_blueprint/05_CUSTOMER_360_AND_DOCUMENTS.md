# 05 — Customer 360 and Documents

## Objetivo

Transformar Cliente em um cadastro completo e central.

## Tela Cliente 360

Abas:
- Resumo
- Dados Pessoais
- Endereços
- Dependentes
- Documentos
- Preferências
- Histórico
- Financeiro

## Dados pessoais

- Nome completo

- Data de nascimento
- Nacionalidade
- Estado civil
- Profissão
- CPF
- RG
- Órgão emissor
- Data de emissão
- E-mail
- Telefone
- WhatsApp
- Observações

## Endereços

## Documentos

Tipos:
- CPF
- RG
- CNH
- Passaporte
- Visto
- Certidão de nascimento
- Autorização de viagem
- Carteira/Certificado de vacinação
- Seguro viagem
- Outros

Campos:
- Número
- País emissor
- Emissão
- Validade
- Frente
- Verso
- Status
- Observações

## OCR-ready

Fluxo:
Upload → Extração → Comparação → Revisão → Aprovação

Exibir:
- Nome extraído
- Nascimento
- Número
- Nacionalidade
- Validade
- Confiança
- Divergências

Nunca substituir cadastro automaticamente.

## Requisitos de viagem

- Passaporte válido
- Visto
- Vacinação
- Seguro
- Autorização
- Outros

Dados de vacinação são sensíveis e devem ter acesso restrito.
