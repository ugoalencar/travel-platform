# 04 — Platform Admin Separation

## Objetivo

Separar visual e funcionalmente o Admin da Plataforma do Admin da Agência.

## Admin da Plataforma

### Dashboard
- Agências ativas
- MRR
- Usuários ativos
- Incidentes
- Saúde do sistema
- Tickets de suporte
- Crescimento
- Assinaturas

### Navegação
- Visão Geral
- Agências
- Planos e Assinaturas
- Faturamento SaaS
- Usuários
- Suporte
- Incidentes
- Feature Flags
- Monitoramento
- Relatórios
- Configurações

## Não mostrar como módulo principal
- Booking
- Aéreo
- Terrestre
- Clientes da agência
- Comissões internas da agência
- Caixa operacional da agência

## Identidade visual

Pode compartilhar design system, mas:
- header distinto
- ícone/cor de papel diferente
- linguagem de governança
- KPIs de plataforma
- sem navegação operacional da agência
