# 07 — Employees, Salaries and Commissions

## Funcionário ≠ Usuário

User:
- identidade de acesso

Employee:
- registro de pessoal e financeiro

## Cadastro do funcionário

- Nome
- CPF
- RG
- Data de nascimento
- Endereço
- Telefone
- E-mail
- Admissão
- Desligamento
- Cargo
- Departamento
- Centro de custo
- Gestor
- Tipo de vínculo
- Salário-base
- Regra de comissão
- Dados bancários
- PIX
- Status
- Observações

## Comissão

Planos:
- % sobre venda
- % sobre margem
- valor fixo
- por produto
- por destino
- por faixa/meta

Fluxo:
Venda → Funcionário → Plano → Comissão → Aprovação → Contas a Pagar → Caixa

## Salários e benefícios

Controle gerencial:
- Competência
- Salário base
- Benefícios

- Bônus
- Reembolsos
- Comissões
- Descontos
- Líquido

- Adiantamento
- Falta

- Outros
