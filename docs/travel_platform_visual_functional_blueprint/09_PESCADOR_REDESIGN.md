# 09 — Pescador Redesign

## Objetivo

Pescador deve parecer ferramenta de captura e transformação de oportunidade.

## Fluxo

1. Colar URL
2. Capturar
3. Extrair
4. Pré-visualizar
5. Revisar
6. Editar
7. Aprovar
8. Criar Oferta
9. Publicar / enviar para campanha / usar em proposta

## Tela

### Área 1 — Captura rápida
- URL
- botão Capturar
- origem
- status da captura

### Área 2 — Dados extraídos
- título
- destino
- validade
- preço
- moeda
- descrição
- imagens
- fornecedor/origem

### Área 3 — Revisão
- erros
- campos faltantes
- divergências
- edição manual

### Área 4 — Resultado
- criar oferta
- enviar para marketing
- vincular a campanha
- usar em proposta

## Se scraping não puder ser total

Permitir:
URL + extração parcial + revisão manual.

Mas nunca voltar a parecer apenas um cadastro genérico.
