# 03 — Customer Portal UX

## Objetivo

O Portal do Cliente deve parecer outro produto, não uma cópia do painel interno.

## Navegação

- Início
- Minhas Viagens
- Propostas
- Reservas
- Documentos
- Pagamentos
- Perfil
- Ajuda

## Home

Mostrar:
- próxima viagem
- contagem regressiva
- situação da reserva
- documentos pendentes
- próximos pagamentos
- mensagens da agência
- atalhos para voucher e itinerário

## Viagem

Seções:
- Resumo
- Itinerário
- Aéreo
- Terrestre
- Passageiros
- Documentos
- Pagamentos
- Contato da agência

## Não expor

Nunca mostrar:
- custo de fornecedor
- margem
- comissão
- DRE
- contas a pagar internas
- dados de funcionários
- negociação com fornecedor

## Visual

Mais leve e emocional:
- imagens de destino
- cards de viagem
- timeline
- status claros
- linguagem amigável
- menos tabelas administrativas
