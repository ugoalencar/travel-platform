## Regra de UX

O usuário deve conseguir entender:
- onde está;
- qual setor está usando;
- qual ação deve fazer;
- como voltar para o fluxo anterior.

Breadcrumbs e ações relacionadas devem ser obrigatórios nas telas principais.
