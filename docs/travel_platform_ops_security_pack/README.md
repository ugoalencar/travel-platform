# Travel Platform — Operations & Security Hardening Pack

Pacote paralelo para operação, atualização, suporte técnico, observabilidade e hardening de segurança.

## Objetivos
- Atualizações SaaS seguras
- Feature flags, versionamento e rollback
- Central de suporte e incidentes
- Logs, métricas e tracing
- Proteção contra SQL Injection
- Proteção SSRF no Pescador
- XSS, CSRF, IDOR/BOLA, path traversal
- Uploads/tokens/webhooks seguros
- HTTPS/TLS, CORS e security headers
- Backup, restore e disaster recovery
- Gates de segurança no CI

## Regra
Não reconstruir funcionalidades já prontas. Proteger e operar o sistema existente.

## Agentes
1. Release & Deployment
2. Support & Observability
3. Application Security
4. Infrastructure & TLS
5. Backup & DR
6. Security Integrator
