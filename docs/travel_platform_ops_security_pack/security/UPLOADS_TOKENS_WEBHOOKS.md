# Uploads, Tokens e Webhooks

## Upload
- MIME real
- tamanho
- filename seguro
- storage tenant-scoped
- signed URL
- bloquear path traversal
- nunca confiar só em extensão

## Tokens públicos
- alta entropia
- expiração
- revogação
- hash quando aplicável
- rate limit
- one-time quando necessário

## Webhooks
- assinatura
- timestamp
- replay prevention
- idempotency
- tenant server-side
