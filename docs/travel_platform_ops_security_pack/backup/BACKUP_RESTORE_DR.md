# Backup / Restore / DR

Backup:
- automático
- retenção
- criptografia
- acesso restrito

Restore:
- testar em ambiente efêmero
- validar schema
- validar registros
- smoke básico

Meta inicial sugerida:
RPO ≤ 1h
RTO ≤ 4h

Valores finais exigem decisão humana.

Runbook:
Detectar → Conter → Comunicar → Recuperar → Validar → Postmortem.
