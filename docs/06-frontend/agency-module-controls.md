# Controles de módulos no app da agência

A página **Configurações → Módulos** permite a Owner/Admin escolher quais
módulos opcionais ficam disponíveis. Todos começam habilitados por padrão; a
disponibilidade final também respeita o plano. O núcleo fica bloqueado.

Quando um módulo é desativado, o menu correspondente desaparece e o acesso por
link direto exibe o motivo e informa que os dados foram preservados. O seletor
identifica módulos que precisam ser desligados antes e módulos não liberados
no plano. Mudar a visibilidade no navegador não substitui as validações da API,
do plano ou das permissões de cada funcionário.
