# 01 — Execution Strategy

## Princípio
Preservar regras. Reconstruir apresentação.

## Ondas

tokens, tipografia, spacing, radius, shadows, cores, ícones.

### V2 — Shell
sidebar, topbar, breadcrumbs, page header, content grid, identidade por papel.

### V3 — Páginas âncora
Agency Dashboard, Cliente 360, Financeiro.

Operação, Staff, Platform Admin, Portal Cliente, Pescador.

### V5 — Forms + Tables + Polish
formulários, tabelas, filtros, responsividade, microinterações.

## Não tocar

- RBAC
- RLS
- tenant context
- contratos de API
- regras financeiras
- migrations aplicadas
